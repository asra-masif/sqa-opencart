# sqa-opencart
# OpenCart Software Testing

This repository contains automated testing of the OpenCart e-commerce website using Python and Playwright. It includes functional, non-functional, smoke, regression, and end-to-end test cases.

The project consists of individual test scripts for 3 members, along with a combined testing script (`opencart_tests.py`). Tests are executed using GitHub Codespaces, with results and screenshots generated automatically.
